### 5.1. Данные Платформенной учётной записи

При регистрации и использовании Платформенной учётной записи Оператор может обрабатывать:

- никнейм (отображаемое имя);
- адрес электронной почты;
- пароль (хранится в преобразованном (хешированном) виде; Оператор не хранит пароль в открытом виде);
- код подтверждения адреса электронной почты и сведения о факте подтверждения;
- уникальный идентификатор учётной записи;
- сведения о статусе поддержки проекта (при наличии);
- токены доступа и обновления сессии, выдаваемые Сервисом.

### 5.2. Связанные игровые идентификаторы

По инициативе Пользователя к Платформенной учётной записи могут быть привязаны:

- идентификатор и имя пользователя Ely.by;
- идентификатор (UUID) и имя профиля Minecraft (Microsoft);
- технические токены, необходимые исключительно для выполнения привязки.

### 5.3. Данные, связанные с сетевыми функциями Сервиса

При использовании сетевых функций Оператор может обрабатывать:

- список друзей, входящие и исходящие заявки в друзья;
- сведения о присутствии в сети (статус «в сети» / «не в сети», время последней активности);
- сведения о комнатах совместной игры: идентификатор комнаты, владелец, состав участников, роль, статус, приглашения;
- уведомления (заявки в друзья, приглашения в комнату, системные сообщения, достижения);
- достижения Пользователя и дату их получения;
- статистику использования: количество запусков игры, суммарное время сессий, дату первого и последнего запуска;
- сведения о сессии лаунчера: идентификатор сессии, наименование клиента, сведения о платформе (тип операционной системы, сообщаемый средой исполнения), версия лаунчера, время создания, время последнего подтверждения активности и время завершения сессии.

### 5.4. Данные, обрабатываемые для организации однорангового соединения

Для соединения Пользователей в рамках совместной игры Сервис использует сигнализацию и, при необходимости, серверы ретрансляции (STUN/TURN). В этом случае могут обрабатываться:

- сигнальные сообщения (SDP, ICE-кандидаты);
- сетевые адреса (включая IP-адрес) и порты, необходимые для установления соединения;
- кратковременные учётные данные для доступа к серверу ретрансляции.

Указанные сведения используются исключительно для организации игрового соединения и не применяются Оператором в рекламных целях.

### 5.5. Технические и журнальные сведения

При обращении к серверной инфраструктуре Оператора автоматически могут обрабатываться:

- IP-адрес;
- дата и время запроса;
- сведения о запрошенном ресурсе и коде ответа;
- идентификатор пользовательского агента (User-Agent);
- иные технические параметры, необходимые для обеспечения работоспособности, защиты от злоупотреблений и диагностики сбоев.

### 5.6. Данные, хранящиеся преимущественно на устройстве Пользователя

На устройстве Пользователя (в каталоге данных приложения и в локальном хранилище) могут сохраняться:

- токены Платформенной учётной записи;
- кэш изображений (в том числе скинов и аватаров);

Оператор не получает автоматического доступа к файлам сохранений, скриншотам, журналам сбоев Minecraft и содержимому игрового каталога, за исключением случаев, когда соответствующая функция явно инициирована Пользователем (например, экспорт профиля, просмотр снимков экрана в интерфейсе лаунчера).

### 5.7. Данные, которые Оператор не собирает

Оператор **не осуществляет**:

- скрытый сбор данных для рекламного профилирования;

**Ely.by**  
Используется при входе через Ely.by (OAuth 2.0 и (или) протокол Yggdrasil). Обработка включает обмен данными с `account.ely.by` и `authserver.ely.by`. Токены сохраняются на устройстве Пользователя. Политика конфиденциальности Ely.by публикуется правообладателем соответствующего сервиса.

В ходе установки и обновления игры, среды выполнения Java, модификаций и сопутствующих компонентов клиент может обращаться к:

- CurseForge (`api.curseforge.com` и сети доставки файлов);

Серверная инфраструктура Оператора (`api.16-launcher.ru` и связанные узлы) обрабатывает данные Платформенной учётной записи и сведения, указанные в разделах 5.3–5.5.

При совместной игре участники комнаты могут получать друг от друга сетевые адреса, необходимые для установления соединения. Если прямое соединение невозможно, трафик может передаваться через сервер ретрансляции (TURN). Оператор использует такие сведения исключительно для обеспечения соединения.

### 9.4. Discord

При наличии установленного и запущенного клиента Discord лаунчер может передавать в локальный клиент Discord сведения о статусе активности (например, факт использования лаунчера и сведения об игровой сессии) посредством Discord Rich Presence. Указанная передача осуществляется на устройство Пользователя и далее обрабатывается Discord в соответствии с правилами Discord. Политика конфиденциальности Discord: [https://discord.com/privacy](https://discord.com/privacy).

## 11. Сроки хранения персональных данных

Персональные данные обрабатываются и хранятся не дольше, чем этого требуют цели обработки, если иной срок не установлен законодательством Российской Федерации.

Ориентировочные сроки:

| Категория сведений | Срок хранения |
| --- | --- |
| Данные Платформенной учётной записи | в течение срока существования учётной записи, а после её удаления — в течение срока, необходимого для завершения процедур удаления и исполнения обязанностей, установленных законом |
| Токены сессии | до истечения срока действия, выхода из учётной записи либо удаления учётной записи |
| Сведения о друзьях, комнатах, уведомлениях и достижениях | в течение срока существования учётной записи либо до удаления соответствующего объекта Пользователем |
| Статистика запусков | в течение срока существования учётной записи |
| Сведения о сессиях лаунчера | в течение срока активности сессии и ограниченного периода после её завершения, необходимого для обеспечения безопасности |
| Журналы обращений к серверной инфраструктуре | в течение срока, необходимого для обеспечения безопасности и диагностики, после чего уничтожаются либо обезличиваются |
| Коды подтверждения электронной почты | в течение короткого срока действия кода |
| Учётные данные STUN/TURN | в течение короткого срока действия, исчисляемого минутами |
| Локальные данные на устройстве Пользователя | до их удаления Пользователем либо удаления приложения |

По истечении срока хранения персональные данные уничтожаются либо обезличиваются, если иное не предусмотрено законодательством.
