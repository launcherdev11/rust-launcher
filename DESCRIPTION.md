# 16Launcher

Лаунчер для Minecraft на Rust и Tauri. Работает на Windows, Linux и macOS, весит немного и не тормозит.

Сайт: https://16-launcher.ru

Ниже полный список возможностей.

## Версии игры и загрузчики

- Установка ванильных версий, включая снапшоты и alpha-версии (показ включается в настройках).
- Установка Fabric, Quilt, Forge и NeoForge. Для загрузчиков можно выбрать конкретную сборку и канал (stable, beta, alpha).
- Запасной прокси для загрузки Forge, если основной источник недоступен.
- Переустановка и удаление версии. При удалении можно убрать только игру, только загрузчик или всё сразу.
- Импорт собственной версии из `.jar`.
- Проверка целостности файлов версии с предложением перезаписать повреждённые.
- Фильтры списка версий по загрузчику и номеру.

## Java

- Нужную версию Java лаунчер скачивает сам.
- Поиск уже установленных Java в системе, ручной выбор пути.
- Выбор объёма памяти в ГБ или МБ.
- Свои JVM-аргументы с проверкой, пресеты «Баланс», «Макс. производительность» и «Низкая память», сброс к рекомендованным.
- Настройки Java отдельно для каждой сборки.
- Проверка и переустановка скачанных рантаймов.
- Предпочтение IPv6.

## Запуск игры

- Запуск выбранной сборки одной кнопкой, остановка игры из лаунчера.
- Кнопка «Продолжить»: сразу открывает последний мир или подключается к последнему серверу.
- Запуск без сети с любым ником.
- Выбор видеокарты для игры.
- Размер окна игры, закрытие лаунчера при старте, проверка уже запущенных процессов игры.
- Запуск сборки с рабочего стола по ярлыку.
- Поддержка прокси.

## Консоль и диагностика

- Консоль игры в отдельном окне, которое можно отсоединить и вернуть. Фильтры по предупреждениям, ошибкам и крашам, копирование вывода.
- Анализатор логов: читает консоль, последний лог, crash-репорт и JVM-краш, показывает найденные проблемы и подсказки.
- Правила для частых падений: сломанная сущность, зависание встроенного сервера, переполнение стека, удалённые моды в мире, отсутствие xrandr на Linux, конфликт с OptiFine.
- Быстрые исправления из анализатора: отключить проблемный мод, добавить памяти, вернуть автовыбор Java.
- История запусков: полный лог каждого запуска с кодом выхода и длительностью, поиск по запускам, копирование отчёта. Хранятся последние 40 запусков.

## Сборки (профили)

- Каждая сборка хранится отдельным профилем со своей версией, загрузчиком, папкой и настройками.
- Создание, переименование, дублирование, смена версии игры, удаление, в том числе нескольких сразу.
- Группы сборок с цветами, вид списком или сеткой, закрепление сборок в боковой панели.
- Иконка сборки из файла или из текстур игры.
- Счётчик времени в игре.
- Свои настройки сборки: аккаунт, размер окна, память, показ консоли, закрытие лаунчера.
- Пресеты сборок: сохранить параметры и применить при создании новой.
- Ярлык сборки на рабочем столе.
- Размер сборки на диске и очистка ненужных файлов.

## Содержимое сборки

- Вкладки «Моды», «Ресурспаки» и «Шейдеры».
- Включение и отключение файлов, массовое включение, отключение и удаление, фильтры по состоянию.
- Добавление файлов с компьютера и перетаскиванием.
- Порядок ресурспаков перетаскиванием.
- Включение и отключение шейдеров.
- Наборы модов: группы модов, ресурспаков и шейдеров, которые лаунчер скачивает под версию игры и загрузчик каждой сборки. Набор можно добавлять во все новые сборки автоматически.
- Определение источника файла (Modrinth или CurseForge) по хешу.

## Моды

- Каталог Modrinth и CurseForge прямо в лаунчере.
- Фильтры по версии игры, загрузчику, категориям, окружению, сортировка, избранное, недавно просмотренное.
- Страница проекта с описанием и списком версий.
- Установка в выбранную сборку вместе с зависимостями, пакетная установка.
- Проверка обновлений установленного контента, выборочное и полное обновление, откат последнего обновления.
- Поиск несовместимых файлов и анализ `.jar` на совместимость.
- Конфликты модов: дубликаты, смешанные варианты, несовпадение загрузчика, отсутствующие и отключённые зависимости, неподходящие версии зависимостей, взаимные запреты. У каждого конфликта есть варианты решения.

## Миры, конфиги и серверы

- Список миров сборки, поиск, открытие папки, удаление.
- Бэкапы миров: ручные, автоматические после игры (хранятся 4 последние копии на мир) и страховочные перед восстановлением.
- Карта чанков мира по измерениям, удаление выбранных чанков.
- Редактор конфигов: файлы из `config`, `defaultconfigs` и `options.txt`, поиск по именам и содержимому, проверка TOML, история версий файла перед каждым сохранением.
- Сборка серверного пакета: ядро, Java, память, настройки `server.properties`, моды, EULA. Настройки сохраняются для каждой сборки.

## Бэкапы сборок

- Резервные копии сборки вручную и автоматически, с настройкой числа хранимых копий.
- Копия перед обновлением контента, с вопросом или без.
- Снимки содержимого и восстановление из них.
- Восстановление бэкапа как новой сборки.

## Импорт и экспорт

- Импорт модпаков из Modrinth и CurseForge.
- Открытие файлов `.mrpack` двойным щелчком, импорт перетаскиванием.
- Импорт сборок из PrismLauncher, MultiMC, ATLauncher, GDLauncher и приложения CurseForge с автоопределением и сканированием.
- Экспорт в `.mrpack` или ZIP. Есть пресеты («Рекомендуемый», «Минимальный», «Всё»), исключения по маскам, предпросмотр итогового содержимого и размера.
- Резервная копия настроек самого лаунчера и восстановление из неё.

## Аккаунты и скины

- Вход через Microsoft и Ely.by (через браузер или логином и паролем для Ely.by).
- Несколько аккаунтов с быстрым переключением, отдельный аккаунт для каждой сборки.
- Офлайн-аккаунт.
- 3D-превью скина с анимациями: стойка, ходьба, бег, приветствие, приседание, полёт.
- Загрузка скина (обычная и slim модель), смена скина по нику, библиотека скинов, выбор плаща.
- Статистика: время в игре и число запусков.

## Платформа 16Launcher

- Аккаунт платформы: регистрация с подтверждением по коду из письма, вход, смена ника и пароля, привязка Microsoft и Ely.by, вход через Discord, удаление аккаунта.
- Друзья: поиск, заявки, список с фильтрами «в сети» и «не в сети», время последнего визита, профиль друга.
- Комнаты для игры с друзьями без белого IP и проброса портов: публичные и приватные, пароль, лимит игроков, вход по ID или коду, комнаты друзей, управление версией и загрузчиком комнаты, приглашения.
- Достижения с прогрессом.
- Уведомления: заявки в друзья, приглашения в комнаты, достижения, системные сообщения.
- Статус присутствия в сети.

## Скриншоты

- Просмотр скриншотов каждой сборки, открытие, копирование, удаление, переход в папку.

## Оформление

- Интерфейс на русском, английском, немецком и испанском.
- Свой цвет акцента, адаптивный акцент, готовые палитры.
- Фоновое изображение с размытием, отключение анимаций и тематических украшений.
- Положение боковой панели: слева, справа, сверху или снизу, порядок вкладок.
- Режим разделённого экрана: две вкладки рядом.
- Пользовательские CSS-темы: создание, дублирование, импорт и экспорт ZIP, встроенный редактор с предпросмотром и горячей перезагрузкой, ресурсы темы.
- Звуки интерфейса.

## Удобство

- Командная палитра для быстрого перехода к вкладкам и сборкам и запуска.
- Горячие клавиши: переключение вкладок, история переходов, запуск и остановка игры, создание и импорт сборки, скриншоты, поиск, обновление списка, справка по клавишам.
- Панель активных загрузок с отменой.
- Знакомство с лаунчером при первом запуске: выбор оформления, вход в аккаунт, перенос данных из другого лаунчера. Подсказки-тур по интерфейсу.
- Сворачивание в трей, автозапуск вместе с системой.
- Discord Rich Presence.
- Системные уведомления.
- Проверка обновлений при запуске и автоматическая установка.
- Очистка кэша лаунчера и сброс настроек.
- Запуск только одной копии лаунчера.
