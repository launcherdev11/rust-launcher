Example Theme for 16Launcher
============================

ID: example-theme

This folder is copied to your launcher data directory on first launch:
  Windows: %APPDATA%\16Launcher\themes\example-theme\
  Linux:   ~/.local/share/16Launcher/themes/example-theme/
  macOS:   ~/Library/Application Support/16Launcher/themes/example-theme/

Required files:
  theme.json  — metadata (name, author, description, version)
  style.css   — CSS overrides for launcher UI classes

Full user guide (Russian):
  docs/THEMES.ru.md

You can create your own theme via:
  Settings → Launcher → Custom theme → Create theme

To share a theme, zip the theme folder (must contain theme.json and style.css).
